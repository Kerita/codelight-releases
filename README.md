# CodeLight

A floating traffic light that shows what Claude Code, Codex and Cursor are doing — thinking, coding, waiting for your decision, or done.

**Download:** grab the latest `CodeLight-<version>-mac-universal.dmg` from [Releases](https://github.com/Kerita/codelight-releases/releases/latest). Works on Apple Silicon and Intel Macs, macOS 12+.

- 14-day free trial with every feature. The light and status cards stay free forever after that.
- Buy a license from inside the app (right-click the light → *Buy*), then paste your key to activate.
- The app updates itself automatically from this page.

This repository only hosts release downloads. Questions or bug reports: open an issue.
